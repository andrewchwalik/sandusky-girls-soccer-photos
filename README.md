# Sandusky Girls Soccer Photos

A mobile-friendly directory of Google Photos albums from the 2026 Sandusky High School girls soccer season.

## Hosting

GitHub Pages serves the root of the `main` branch. Updates pushed to `main` publish automatically.

## Updating albums

Edit the album links and titles in `index.html`. The cover image is `team-cover.jpg`. No build tools or paid services are required to run this static site.

Open `index.html` in a browser to preview changes locally.
